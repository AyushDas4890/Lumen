# LumenPath Health

Hospital website built with Astryx (`@astryxdesign/core`) + React + Vite, themed from the LumenPath brand guidelines.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Pages: Home, Services, Doctors, Book (4-step flow), My appointments, Contact.
Bookings are stored in the browser's localStorage (no backend). Doctors and details are fictional.
